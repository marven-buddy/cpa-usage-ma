# cpa-usage-ma v0.4.1

基于 andyWang1688/cpa-usage 的 CLIProxyAPI v8 二次开发版本，以独立插件 ID `cpa-usage-ma` 发布，使用独立路由、默认数据目录和浏览器存储。

- 兼容 v8 配置与管理接口；数据库目录自动创建，重配置失败保留原连接。
- 自动读取后台 v1/v2 管理凭据，也可在插件内输入管理密钥，无需后台记住密码。
- 新用量按匿名客户端标识归属，上游来源单独记录；支持 SQLite 持久化 Key 备注。
- 日期筛选、趋势按浏览器时区统计，正确处理跨时区和夏令时边界。

第三方插件源：

```text
https://raw.githubusercontent.com/marven-buddy/cpa-usage-ma/main/plugin-store/registry.json
```

新安装不会读取或迁移原版 `usage-report` 的数据。两者可并存，但必须使用不同数据库。如需迁移历史，停止相关 CPA 宿主后完整备份并复制 SQLite 到新目录，配置 `plugins.configs.cpa-usage-ma.db_path`；保留旧库用于回滚。旧记录不重写，可能含原始来源字段；不要公开数据库。新记录仅保存匿名标识，备注中不要填写完整密钥。手动管理密钥仅在验证成功后保存在当前标签会话。

安装包使用 `cpa-usage-ma_0.4.1_<goos>_<goarch>.zip` 命名；使用同一 Release 的 `checksums.txt` 校验 ZIP。CI 的 Linux amd64 包基于 glibc 2.35，arm64 包基于 glibc 2.39；不适用于 Alpine/musl。Windows 本地交叉构建可生成 glibc 2.31 的 amd64 包。

已通过 CPA v8.0.48 / Windows amd64 加载测试。Linux amd64 已交叉构建，目标 Linux 宿主加载仍待验收。

已知限制：用量写入错误传播尚不完整，异常时可能漏记；Gemini / Antigravity 独立推理 Token 可能漏计；简化 YAML 解析不覆盖全部写法；大库全历史查询、请求时间排序及价格种子恢复仍待改进。统计和费用仅供参考。
